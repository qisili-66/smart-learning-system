

一、公共约定（前后端必须严格遵守）
更新时间：2026-07-05

1.1 通信与鉴权
1. 通信协议：HTTPS / HTTP（开发环境）
2. 数据格式：请求与响应均使用 application/json（文件上传除外）
3. 全局前缀：/api，本文档中的请求路径均基于该前缀，例如 /auth/login 的完整开发环境地址为 http://localhost:8080/api/auth/login
4. 鉴权方式：JWT Bearer Token
  ○ 需登录接口请求头必须携带：Authorization: Bearer {token}
  ○ Token 无效/过期返回 401，前端统一跳转登录页
5. 角色权限：
  ○ public：公开接口，无需登录
  ○ student：学生角色可访问
  ○ admin：管理员角色可访问
1.2 统一响应结构
所有接口必须返回以下结构，禁止自定义
{
  "code": 200,
  "message": "操作成功",
  "data": null,
  "timestamp": 1719820000000
}
字段	类型	说明
code	int	业务状态码
message	string	状态描述
data	object/array/null	业务数据，无数据返回null
timestamp	long	服务器时间戳（毫秒）
1.3 业务状态码约定
code	含义	说明
200	成功	请求正常处理
400	参数错误	参数校验不通过、格式非法
401	未授权	未登录、Token无效/过期
403	无权限	角色不匹配、无操作权限
404	资源不存在	ID不存在、路径错误
409	业务冲突	数据重复、状态不允许操作
500	服务器错误	程序异常、服务故障
1.4 分页查询统一规范
1. 请求参数：pageNum（页码，默认1）、pageSize（每页条数，默认10，最大100）
2. 响应 data 固定结构：
{
  "list": [],
  "total": 128,
  "pageNum": 1,
  "pageSize": 10,
  "pages": 13
}
1.5 其他约定
● 时间格式：yyyy-MM-dd HH:mm:ss
● URL命名：全小写，多单词用 - 分隔，纯名词，不出现动词
● 字段命名：统一驼峰命名（camelCase），前后端保持一致
● 空值处理：字符串空返回 ""，数字空返回 null，集合空返回 []
