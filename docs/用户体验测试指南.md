# 用户体验测试指南

更新时间：2026-07-06

## 目标

用少量演示数据跑通核心业务闭环：

`组卷 -> 答题 -> 批改 -> 出报告 -> 更新画像 -> 错题入本 -> 推荐薄弱知识点资源`

## 1. 准备演示数据

在项目根目录执行：

```bat
cd /d D:\zuoye\dasanxia\xiaoxueqi\smart-learning-system
cmd /c "mysql --default-character-set=utf8mb4 -uroot -proot smart_learning_system < docs\sql\f6_f7_demo_learning_loop_seed.sql"
```

这个脚本会导入：

- 10 道数学题：一次函数、二次函数、勾股定理。
- 3 个学习资源：一次函数讲义、二次函数微课、勾股定理专项练习。

如果数据库密码不是 `root`，把 `-proot` 改成实际密码。

## 3. 用户端体验流程

1. 注册或登录学生账号。
2. 进入 `测评中心`。
3. 创建测评：
   - 测评模式：专项测评
   - 学科：数学
   - 难度：基础
   - 知识点范围：一次函数
4. 点击 `生成测评`，页面应显示题目。
5. 故意答错 1-2 道题，再点击 `提交测评`。
6. 页面应显示测评报告，包括得分、正确率、能力分析、提升建议。
7. 进入 `错题本`，应看到刚才答错的题。
8. 进入 `学情画像`，刷新后应看到画像指标或薄弱点发生变化。
9. 进入 `资源库`，画像推荐区域应优先出现对应知识点资源，例如 `一次函数基础讲义`。

## 4. 管理员端同步验证

1. 用管理员账号进入后台。
2. 进入 `题库管理`，确认能看到导入的题目。
3. 新增一道数学题，回到学生端创建同学科测评，确认题目可参与组卷。
4. 进入 `资源管理`，确认能看到演示资源。
5. 将一个资源状态改为停用，学生端资源库应不再展示该资源。
6. 将资源重新启用，学生端刷新后应恢复展示。

## 5. 自动化功能怎么判断生效

这些功能不是按钮式操作，需要看结果：

- 自动批改：提交测评后 `测评报告` 出现得分和正确率。
- 错题采集：故意答错后，`错题本` 出现对应错题。
- 画像更新：提交测评后，`学情画像` 的测评正确率、薄弱点或推荐建议变化。
- 资源推荐：资源库 `画像推荐` 中出现错题/薄弱知识点对应资料。
- 后台同步：后台新增或停用题目、资源后，学生端组卷和资源列表跟着变化。

## 6. 建议重点观察的 Bug

- 测评生成后题目为空：通常是题库没有匹配的学科、难度、知识点。
- 明明答对却判错：检查后台题目答案是否和选项文本一致；当前后端已兼容 `A` 与 `A. xxx` 格式。
- 资源推荐为空：检查是否有同知识点资源，且资源状态为正常。
- 错题本没有新增：确认提交答案的 `questionId` 来自题库，且答案确实与标准答案不一致。
- 学生端看到停用资源：说明资源列表没有按 `status=1` 过滤，需要优先修复。
- 管理员新增资源后学生端看不到：检查资源状态是否为正常、学科和知识点是否填写。
